# 实训学时合规与冻结服务

该服务汇聚学员签到、导师确认和请假修正事件，按培养方案与时区重放学时状态，并保存可追溯的学期冻结快照。项目还提供导师分配、证明材料、豁免复核、规则版本、名额、通知和数据留存等领域模块，供后续业务扩展时复用统一的状态与审计约束。

## 事件顺序模型

事件的业务编号（`event_id`）可能来自不同系统（短数字、带前缀编码等），格式不保证有序，因此**不参与排序**。服务端在导入时为每个培养方案分配持久化的单调序位 `seq`（由 `plan_event_counters` 原子发放，唯一且不复用），重放、截止查询与冻结截止点一律以 `seq` 为准；重复事件按 `(plan_version, event_id)` 幂等忽略，不改变既有序位。冻结快照把截止序位 `event_cutoff_seq` 与展示用的 `event_cutoff_id` 一并持久化，重复冻结返回首次签发结果，迟到补录因序位更高而永远不会被纳入既有冻结。

服务启动时自动执行幂等迁移（`app/migrations.py`）：为旧库的 `events` 回填 `seq`（按历史入库顺序，即 `rowid`）、创建序位索引与计数器、为 `freezes` 增加 `event_cutoff_seq` 列。历史冻结内容保持原样，可继续复现。

## 运行方式

默认数据保存在项目目录的 SQLite 文件中。安装依赖后执行 `uvicorn app.main:app --host 127.0.0.1 --port 8000`，健康检查地址为 `/health`，业务接口位于 `/api`。


测试覆盖事件幂等导入、跨时区与跨日学时合并、实习确认、负向修正、冻结快照和差异查询；运行过程中不需要单独的数据库或网络服务。
